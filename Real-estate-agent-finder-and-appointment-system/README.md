# 🏠 Real Estate Property Management System



## 📋 Overview

A comprehensive Real Estate Property Management System that supports listing properties, booking appointments, rating properties, inquiries, and more. Built with modern, responsive, and dynamic UI elements. Features a Role-Based Access Control (RBAC) separating Client and Admin experiences.


## 🚀 Technologies Used

### Frontend
- React.js 18
- Tailwind CSS
- React Router DOM
- Vite
- Axios
- Lucide React Icons

### Backend
- Spring Boot 3.x
- Java 17
- Spring Data JPA
- Spring Web
- MySQL Connector
- Lombok
- Spring Boot Validation

### Database
- MySQL (via XAMPP / phpMyAdmin)

### Design Patterns
- Object-Oriented Programming (OOP)
  - Encapsulation
  - Inheritance
  - Polymorphism
- MVC Architecture
